# 0.3.2 — 2026-07-31

## Fixed

- **`EIA_DATASET_TTL_SECONDS` now genuinely slides.** `CanvasBridge.registerDataframe` and the `register_as` branch of `query()` pass `ttlMs` to the framework canvas primitive, which extends a table's window on every `eia_dataframe_query` statement that references it; a plain `eia_dataframe_describe` listing does not. `DataframeMeta.expiresAt` and the bridge's own `sweepExpired()` clock are removed — `expires_at` now reads live off `CanvasInstance.describe()` instead of a value frozen at registration. (#30)
- **`eia_dataframe_describe` distinguishes a lookup miss from an empty canvas.** A `name` that is not staged now returns `found: false` plus `active_names` (every handle still staged) instead of the same `{ dataframes: [] }` / "No active dataframes" response an empty canvas produces. New `requested_name` and `found` output fields; `format()` names the usable handles on a miss. (#33)
- **`eia_dataframe_query` declares the error reasons callers actually hit.** `missing_table`, `non_select_statement`, `invalid_sql`, and `register_as_clash` join `errors[]`, each with a recovery phrased in this server's own tool names. `CanvasBridge.query()` now re-throws framework SQL-gate and DuckDB errors with the contract's `recovery` merged onto `data.recovery` — previously the declared `system_catalog_access` recovery never reached the wire, and the framework's own `missing_table` hint named methods (`registerTable()`, `describe()`) no MCP client can call. (#34)
- **Stale dataframe provenance no longer accumulates unboundedly.** The canvas's own sweeper drops expired tables without notifying the bridge; a reconciliation pass now runs on every provenance write path (`registerDataframe`, the `register_as` branch of `query`) as well as `describe`, deleting `ctx.state` entries for tables the canvas no longer holds. A caller that stages and queries but never calls `eia_dataframe_describe` previously accumulated stale entries indefinitely.
- **`eia_dataframe_query`'s `register_as` rejects an empty string** instead of silently registering nothing — the field now requires a non-empty name.
- **`eia_dataframe_drop` treats the canvas as authoritative on existence** — a stale `ctx.state` entry for a table the canvas already dropped no longer reports `dropped: true`; the stored answer is now a fallback only when the canvas itself is unreachable.
