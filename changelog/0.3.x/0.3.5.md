# 0.3.5 — 2026-08-05

## Fixed

- **`eia_query_route` no longer forwards EIA's `incomplete return` advisory when the response already accounts for the gap it names.** The advisory fires whenever the requested `length` is smaller than `total`, at any size — its "5000 rows" text is fixed boilerplate, not a real ceiling report. `truncation_warning` now drops that entry, and only that entry, when the staged canvas table runs to the last row or a `notice` already explains a row-less page; every other advisory EIA reports still forwards. (#41)
- **`sort` now reaches dataframe provenance.** `eia_query_route` passes `sort` into the `queryParams` handed to `registerDataframe` and echoes it as a new `appliedSort` enrichment field (with a trailer renderer for `content[]`). Without it, two opposite-ordered stages of the same capped query described identically in `eia_dataframe_describe`. `eia_dataframe_describe`'s `format()` also now skips `undefined`-valued params instead of rendering the literal string `undefined`. (#44)
- **`canvas_preview_note` now names the staged row range when `offset > 0`.** A stage running from a nonzero offset to the last row previously read identically to a prefix of the same query — both reported only a row count. The range clause the cap and early-stop branches already built is now appended whenever staging starts past row 1. (#45)
