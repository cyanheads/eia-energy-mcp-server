# 0.3.7 — 2026-08-05

## Fixed

- **`EiaApiService.fetchFacet`** now drops a facet value only when its `id` is null. A value whose `name` is null or absent is kept and labelled from its `alias`, falling back to the `id`. Un-hides `electricity/state-electricity-profiles/meters`'s `technology` facet (0 → 4 values) and `electricity/facility-fuel`'s `primeMover` (0 → 21). ([#47](https://github.com/cyanheads/eia-energy-mcp-server/issues/47))
- **`eia_describe_route`**'s `format()` quotes a facet value's `id`/`name` when blank, so a value EIA sends with a single-space identifier — `electricity/facility-fuel`'s `primeMover` unspecified-prime-mover bucket — renders as a visible, copyable pair instead of an empty one in `content[]`. ([#48](https://github.com/cyanheads/eia-energy-mcp-server/issues/48))
