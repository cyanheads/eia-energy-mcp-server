# 0.4.2 — 2026-09-19

## Changed

- **Breaking: Bun** now requires `>=1.4.0`.
- **Route inputs** accept `route` or `path` for browse, describe, and query calls without changing their advertised schemas; calls that supply both are rejected (#63).
- **`MCP_SESSION_MODE`** is explicit across source, `.env.example`, Docker, and the README. With MCP_SESSION_MODE unset, HTTP defaults to stateless; an explicit value still overrides.
- **`@cyanheads/mcp-ts-core`** updates `^0.12.3` → `^0.13.6`: argument rejections use `InvalidParams` (0.12.7) with recovery hints (0.13.3), and DataCanvas conversion errors provide validation recovery guidance (0.13.4).
- **Plugin and hosted installation metadata** now wire the EIA API key through Claude plugin user configuration or a Codex host environment variable, and the README documents the hosted Streamable HTTP endpoint.
- **Development skills** moved to `framework-skills/`, so plugin installs no longer load development guidance; `AGENTS.md` is included in the npm package.
- **EIA request handling** uses framework pacing and HTTP classification: 401/403 refusals do not retry as outages, 501 is nonretryable, and EIA 400 details are retained.

## Security

- **`literalTableCell`** preserves literal EIA and SQL headers and values across HTML and Markdown rendering, escaping markup, table syntax, and line breaks before they can alter output structure (#61).
