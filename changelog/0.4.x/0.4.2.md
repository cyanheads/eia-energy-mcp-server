# 0.4.2 — 2026-09-19

## Changed

- **Breaking: Bun** now requires `>=1.4.0`.
- **Route inputs** accept `route` or `path` for browse, describe, and query calls without changing their advertised schemas; calls that supply both are rejected (#63).
- **`MCP_SESSION_MODE`** is explicit across source, `.env.example`, Docker, and the README. With MCP_SESSION_MODE unset, HTTP defaults to stateless; an explicit value still overrides.
- **`@cyanheads/mcp-ts-core`** updates `^0.12.3` → `^0.13.6`: argument rejections use `InvalidParams` (0.12.7) with recovery hints (0.13.3), and DataCanvas conversion errors provide validation recovery guidance (0.13.4).
- **Plugin and hosted installation metadata** now wire the EIA API key through Claude Desktop user config or a Codex host environment variable, and the README documents the hosted Streamable HTTP endpoint.
- **EIA request handling** uses framework pacing and HTTP error classification for route warmup, facet indexing, and upstream responses.

## Fixed

- **Rendered query tables** preserve literal pipes, backslashes, and line breaks in EIA and DataCanvas values instead of allowing them to reshape Markdown tables (#61).

## Security

- **`literalTableCell`** escapes client-visible table cells before Markdown rendering, preventing EIA data values from altering the surrounding table structure (#61).
