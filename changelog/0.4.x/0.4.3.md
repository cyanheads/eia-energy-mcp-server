# 0.4.3 — 2026-10-03

## Changed

- **Declared recovery** now uses the framework's automatic hint fill for unavailable DataCanvas and inverted date ranges; the canvas bridge retains EIA-specific overrides.
- **Framework error handling** adopts JSON storage and stack redaction (0.13.7), output-contract and SQL binder classification (0.13.8), stringified-object and safe-integer input repair plus private canvas scratch directories (0.13.9), recovery hints and request IDs (0.13.10), and client log redaction and level filtering (0.13.11).
- **Docker** cross-installs production dependencies on the build host, installs OpenTelemetry peers at framework-declared ranges, and removes musl bindings from the glibc runtime image.
- **Development tooling and guidance** sync with the framework, including definition-import failures, packaging and tag checks, CodeQL language categories, environment-file exclusions, and DataCanvas availability documentation.

## Fixed

- **MCP Registry launch metadata** runs the npm bin through `npx` and fixes `MCP_TRANSPORT_TYPE=http` on the HTTP entry.
- **Package contents** exclude built `.mcpb` files from npm and logs and design notes from the desktop bundle; the 0.4.1 changelog no longer contains stray markup.
