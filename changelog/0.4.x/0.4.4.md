# 0.4.4 — 2026-10-12

## Added

- **`eia_search_routes`** indexes SEDS's 968 named series beside STEO's, each hit carrying `filter_hint: { seriesId }` (#57).
- **`eia_search_routes`** `limit` accepts up to 100; a call returns at most 30 and discloses the cap in `cap`, `truncated`, and the notice (#70).
- **`eia_query_route`** `next_offset` continues a page cut at the byte budget (#58).
- **`eia_describe_route`** `unavailable_facets` names facets whose value list EIA did not return; the next describe re-fetches only those (#59).
- **Declared reasons:** `facet_unavailable` (#59); `uri_too_long` on `eia_query_route` (#71); `upstream_unreachable` on all four route tools (#72); `rate_limited` on browse and search (#75); `canvas_drop_failed` on `eia_dataframe_drop` (#60).

## Changed

- **`eia_query_route` and `eia_dataframe_query`** hold each response surface to 64,000 bytes, cutting between whole rows; staging still receives every fetched row (#58).
- **`eia_query_route`** without `columns` reads data column IDs from the route tree and fetches no facet value lists (#69).
- **`canvas_preview_note`** names `eia_dataframe_describe` for staged column names, then `eia_dataframe_query`, whenever `dataset` is set (#62).
- **Cold start:** the route-index warm outlives the request that starts it and stops only at server shutdown; browse, describe, and query wait at most 20 s for it, then answer from a live fetch of their own route (#67, #74).

## Fixed

- **`eia_search_routes`** `query` is trimmed, and an empty or whitespace-only value is rejected as `invalid_arguments`; it previously returned arbitrary routes (#55).
- **`eia_search_routes`** reports `truncated: true` only when more matches exist than were returned (#56).
- **`eia_search_routes`** ranks a route first when the query spells the end of its path in words, e.g. `retail sales` for `electricity/retail-sales` (#73).
- **`eia_query_route`** drops empty filter arrays from the request and the `appliedFilters` echo (#55).
- **`eia_query_route`** ignores `period` and the route's facet IDs in `columns` instead of failing the call (#65).
- **`eia_describe_route`** no longer caches a facet whose fetch failed as an empty list (#59).
- **DataCanvas:** a failed stage returns the inline rows with a note and no `dataset`; a failed drop fails as `canvas_drop_failed` and keeps the table listed (#60).
- **EIA 414 responses** fail once as `uri_too_long` instead of being retried as `rate_limited` (#71).
- **Network failures** reaching EIA return retryable `upstream_unreachable` instead of an internal error, with the API key kept out of the message (#72).
