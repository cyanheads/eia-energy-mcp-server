# 0.4.5 — 2026-10-21

## Changed

- **DataCanvas** defaults to DuckDB on Bun and Node.js; `CANVAS_PROVIDER_TYPE=none` disables it. Staging still requires `stage: true`, and dataframe drop retains its separate opt-in.
- **Row bounds** accept over-cap integers and disclose requested/effective values: search `limit` clamps to 30, query `length` to 5000, and dataframe `row_limit`/`preview` to 10000. Empty results disclose clamping too. ([#85](https://github.com/cyanheads/eia-energy-mcp-server/issues/85))
- **Route paths** accept one complete leading `/v2/` segment after whitespace/slash normalization, sharing canonical output and caches with bare routes. ([#86](https://github.com/cyanheads/eia-energy-mcp-server/issues/86))

## Fixed

- **Upstream failures** distinguish unusable responses (`upstream_invalid_response`) from retryable HTTP outages (`upstream_unavailable`); genuine rate limits include wire retryability. All four route tools declare recovery guidance. ([#77](https://github.com/cyanheads/eia-energy-mcp-server/issues/77))
- **Query filters** name unmatched values and suggest case-sensitive IDs from complete cached vocabularies without fetching more metadata or changing submitted filters. ([#81](https://github.com/cyanheads/eia-energy-mcp-server/issues/81))
- **Monthly date bounds** disclose that a year-only start or end means January for effective `YYYY-MM` data; the end notice points to December for a full year. ([#82](https://github.com/cyanheads/eia-energy-mcp-server/issues/82))
- **Describe date ranges** identify their default-frequency context and disclose that another frequency may extend outside the reported endpoints. ([#83](https://github.com/cyanheads/eia-energy-mcp-server/issues/83))
- **SQL recovery** declares `denied_function`, `multi_statement`, and `sql_read_only` with tool-specific hints while preserving the framework's reasons and codes. ([#84](https://github.com/cyanheads/eia-energy-mcp-server/issues/84))
- **Claude Desktop bundle** pins the canvas off because native DuckDB bindings are excluded; cache artifacts are excluded too.
