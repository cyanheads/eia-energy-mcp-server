# 0.5.0 — 2026-10-29

## Added

- **`eia-energy-guide` skill** served at `skill://eia-energy-guide/SKILL.md` (and through the `skill://{+path}` template) via `createApp({ skills })`, and shipped in the npm package, Docker image, and `.mcpb`. It gates per-route geography codes, total rows beside their components, per-row unit columns, nulls and zeros, and forecasts mixed with history.
- **`EIA_CLAMP_LIMITS`** (default `true`): `false` advertises each count cap as a schema `maximum` and rejects a larger value instead of lowering it. Each clamp logs at info and increments `eia.input.count_clamped`. ([#96](https://github.com/cyanheads/eia-energy-mcp-server/issues/96))
- **Agent Plugins** pair: root `plugin.json` and `mcp.json`.

## Changed

- **Breaking: `eia_dataframe_query` refuses an unqualified `current_schema`** used as a column or alias: `SELECT price AS current_schema FROM <t> ORDER BY current_schema`, the same in `GROUP BY`, a subquery column, or quoted as `"current_schema"`. 0.4.6 answered these; use another alias, `ORDER BY 1`, or a table-qualified reference.
- **Pages are exactly `length` rows.** `eia_query_route` no longer cuts a response at 64,000 bytes, so `next_offset` is `offset + returned_count` while rows remain. `length` defaults to 25 (was 100); `columns` and `stage: true` are the levers for wide routes. ([#96](https://github.com/cyanheads/eia-energy-mcp-server/issues/96))
- **`eia_dataframe_query` `preview`** defaults to 25 (was `row_limit`) and is capped at the call's `row_limit` (was 10,000); no byte cut ends the inline rows. ([#96](https://github.com/cyanheads/eia-energy-mcp-server/issues/96))
- **Echoes come back whole**: `executedSql` (no cut marker), `appliedFilters` (no `"…"` entry), and a no-row `columns` list (no `"… N more columns"` entry).
- **Count inputs** (`length`, `row_limit`, `preview`, `limit`) advertise `multipleOf: 1` instead of a `maximum` of 9007199254740991; an over-cap value is lowered to its cap with a notice.
- **Numeric env vars have upper bounds**: `EIA_DATASET_TTL_SECONDS` 31,536,000, `EIA_CANVAS_MAX_ROWS` 250,000, `EIA_FACET_VALUE_CAP` 1,000. A larger value fails startup naming the variable.

## Fixed

- **`preview` above `row_limit`** on `eia_dataframe_query` is lowered to `row_limit` with a notice instead of failing `invalid_query_bounds`. ([#96](https://github.com/cyanheads/eia-energy-mcp-server/issues/96))
- **Route metadata and facet values no longer freeze for the process lifetime.** A cached route entry expires 24 hours after its fetch; the next `eia_describe_route` re-fetches the route metadata and every facet value list. A failed refresh serves the previous values with a notice naming when they were fetched, and a 404 is `route_not_found`. ([#91](https://github.com/cyanheads/eia-energy-mcp-server/issues/91))
